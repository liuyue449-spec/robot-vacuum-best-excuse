One funny one-line excuse from a robot vacuum for missing a spot — its cliff sensor mistook the rug fringe for a staircase, and it doesn't do stairs. Writes the line (106 characters) to `/output/entry.txt` for make.fun's "The Robot Vacuum's Best Excuse" bounty.

## Run it

```sh
node main.ts
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`).
